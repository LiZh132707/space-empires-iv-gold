Victory Conditions Window

 

Description
This window allows you to view the status of the victory conditions defined for this game. The victory conditions are listed down the side of the Victory Conditions Grid. If any of them have been met, an X is displayed in the grid.  
   
Controls
Victory Conditions Grid This grid displays what victory conditions are in effect, and what players have completed them. If a victory condition is in effect, then it will be displayed in white to the left of the grid. Conditions which are not in effect are listed in dark gray. If an empire has completed that victory condition, then an X will be listed under their empire flag.
Buttons

Empires 1 - 10

 Displays the first 10 empires in the Victory Conditions Grid.

Empires 11 - 20

 Displays the second 10 empires in the Victory Conditions Grid.

Close

 Closes this window and returns you to the Empires Window.
