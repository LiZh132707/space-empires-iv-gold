Formation Report Window

 

Description

This window displays details about the selected formation. You can get this report by right-clicking on any formation you see on any window, or by going into the Help Window and selecting a formation.

A formation is an arrangement of ships within a fleet. If you select a given formation for a fleet, then the ships in it will try to form that pattern seen here when moving.

 
   
Controls
Formation Display The arrangement of the ships around the Lead Ship. The Lead Ship is denoted with an "L" on the diagram. After the lead ship, each ship is placed in order based on the numbers in the diagram. In combat, when you move ships in a combat group, each of the ships in the group will move to form this pattern when the group leader moves.
Buttons
(Click) You can close this report window by clicking anywhere on it.
