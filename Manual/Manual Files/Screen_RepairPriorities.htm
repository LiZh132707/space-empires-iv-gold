Repair Priorities Window

 

Description
This window allows you to choose the order in which you want components repaired on your ships.  
   
Controls
Component Groups This lists presents all of the different component groups that you know of. By left-clicking an item in this list, it gets moved to the Group Repair Priority list.
Group Repair Priority This lists the component groups in the order that you want them repaired. When one of your ships is damaged, and it undergoes repair, the components are repaired in the order of the group they belong to in this list. Left-clicking an item in this list will move it back to the Component Groups list.
Buttons
Remove All Removes all of the items currently in the Group Repair Priority list.
Close Closes this window and returns you to the Empire Status Window .
