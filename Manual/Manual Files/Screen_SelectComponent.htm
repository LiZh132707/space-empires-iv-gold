Select Component Window

 

Description
This window allows you to select a component from the undamaged components on your ship. Usually, this window is used to allow you to choose a component to use. Using a component is for components that have one single use and then they are destroyed. For example, the Emergency Propulsion component is used to give you added movement for a given turn. Once used, it is then destroyed.  
   
Controls
Component List Lists all of the components on your ship that can be selected for use. Left-click on a component to choose that one.
Buttons
Cancel Cancels your current selection and returns you to the Main Window.
   
Special Notes
