Load Game Window

 

Description
This window allows you to select a game to load.  
   
Controls
Save Game List A list of the current savegame files found in your savegame directory. Each file is listed with just its name (no extension) and the date it was last modified. Click on a game in the list to select it for loading.
   
Buttons
Cancel Cancels loading a game and closes the window.
   
Special Notes
None
