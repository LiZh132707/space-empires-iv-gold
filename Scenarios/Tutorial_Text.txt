=======================================================================================
SCENARIO TEXT DATA FILE
=======================================================================================

ID:
  Unqiue identifier for this scenario segment.

Series:
  The grouping for this scenario segment. All items with the
  same series number which are in order, will be viewable by
  the player by hitting previous \ next. 

Segment:
  The order number within this series. 

Turn:
  The turn that this item should be displayed. Numbering starts
  at zero which is the first game turn.

For Players:
  The list of all players that should see this text on their
  turn.

Text Number of Paragraphs:
  The number of paragraphs for the text box.

Text Paragraph #:
  The text for the paragraph. Indentation is taken care of by 
  the program.

Image:
  The bitmap name to display in the Scenario Text window. The
  bitmap must be located in the Scenarios directory.
